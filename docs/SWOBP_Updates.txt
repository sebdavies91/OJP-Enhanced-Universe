Update 1 28/07/2026 (Initial SW Open Battlefront Project Release - Major Rebrand, Source Transition, Gameplay Upgrade and Latest Patch)

All the changes below belong to the same 28/07/2026 SW Open Battlefront Project update. The subsections are only area classifications so the update remains readable.

A) PROJECT IDENTITY, LAUNCHERS AND NAMING
-----------------------------------------

1) Renamed the project identity from SW OJP Enhanced Universe to SW Open Battlefront Project.

2) Changed the active mod folder identity from ojpenhanced to openbattlefrontproject.

3) Updated the executable launch logic so the vanilla launcher starts the game with fs_game set to openbattlefrontproject.

4) Updated the OpenJK launcher so it also starts the game with fs_game set to openbattlefrontproject.

5) Renamed the main vanilla launch batch to SW_Open_Battlefront_Project_Vanilla.

6) Renamed the main OpenJK launch batch to SW_Open_Battlefront_Project_OpenJK.

7) Updated the internal game version string from OJP Enhanced Universe to Open Battlefront Project.

8) Updated the client compatibility keyword from the old OJP Enhanced naming to the new Open Battlefront Project naming.

9) Updated the server browser keyword so SWOBP servers can be identified separately from old OJPEU servers.

10) Updated the default message of the day to welcome players to Open Battlefront Project.

11) Updated several source comments and project references from OJP/OJPEU wording to OBP/SWOBP wording.

12) Preserved the legacy relationship with SW OJP Enhanced Universe while making the new project clearly independent in naming and server identity.

13) This change avoids presenting SWOBP as only a small OJPEU patch; it is now a new project branch with its own name, folder, launchers and server keyword.

14) Existing player or server configs using old ojp_* names should be reviewed because several internal names now use obp_* naming.

15) Old OJPEU servers and new SWOBP servers should not be assumed to be automatically compatible without testing.
