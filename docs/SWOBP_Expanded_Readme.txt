GENERAL DESCRIPTION
============================================================================================================================================

This document provides installation, first-run, later-run, configuration, related-documentation, credits-reference and legal information for the Expanded release of SW Open Battlefront Project.

============================================================================================================================================
INSTALLATION INSTRUCTIONS
============================================================================================================================================

Copy and paste all included folders, libraries and executables into the Jedi Academy/GameData folder.

============================================================================================================================================
BEFORE PLAYING
============================================================================================================================================

Make sure you delete any previous jampconfig.cfg file from the Jedi Academy/GameData/openbattlefrontproject folder before playing this release.

============================================================================================================================================
HOW TO RUN
============================================================================================================================================

A) FIRST RUN
------------

Either double click on "SW_Open_Battlefront_Project_Vanilla" to execute the game via the vanilla executables (recommended), or double click on "SW_Open_Battlefront_Project_OpenJK" to execute the game via the OpenJK executables.

B) LATER RUNS
-------------

Either double click on "Play_SW_Open_Battlefront_Project_Vanilla" to execute the game via the vanilla executables (recommended), or double click on "Play_SW_Open_Battlefront_Project_OpenJK" to execute the game via the OpenJK executables.

============================================================================================================================================
WHILE PLAYING
============================================================================================================================================

Type /rate 90000 in the console.
